# card-game-1-learning

一个可运行的 Python 命令行卡牌小游戏（3 人，1v2 非对称，MVP-0）。

## 规则（MVP-0）

HEAD
- 牌库共 29 张，仅包含名称与数量（不实现技能），使用正式牌库定义（见 `game/cards.py`）。
- 开局：每人 9 张手牌，剩余 2 张为底牌并公开可见；在阵营确定后两张底牌归进攻方，进攻方手牌变为 11 张。
- 阵营：
  - 手牌含“快手杰克”的玩家为进攻方；
  - 若无人拥有“快手杰克”，随机指定进攻方；
  - 其余两名玩家为防守方，按玩家编号小者=抗压位，大者=支援位。
- 回合流程：
  1. 出牌阶段：按 `进攻方 -> 抗压位 -> 支援位` 顺序，各自背面放置 1 张。
  2. 信息可见性：支援位可见抗压位放置的牌，其余背面信息不可见。
  3. 启动阶段（占位）：可选择是否翻面自己放置的牌（仅记录翻面状态，不触发技能）。
  4. 回合结束：
     - 翻面牌进入弃牌区（永久移出）；
     - 未翻面牌回到所属玩家手牌；
     - 若本轮无人翻面，则战场所有牌直接进入弃牌区。
- 胜利条件：出牌阶段时若某阵营所有玩家均无牌可出，则该阵营失败。
- 平局条件：若出牌阶段开始时进攻方与两名防守方都无牌可出，则直接判定平局。


## Windows 环境运行

### 1) 创建并激活虚拟环境

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2) 安装依赖

```powershell
python -m pip install -U pip
pip install pytest
```

### 3) 运行游戏

```powershell
python main.py
```

## 输入说明

- 出牌阶段：输入手牌索引（如 `0`、`1`）选择本回合背面放置的牌。
- 启动阶段：输入 `y` / `n`（或 `yes` / `no`）决定是否翻面自己战场牌。
- 程序会显示：
  - 公开底牌；
  - 每位玩家角色；
  - 支援位可见的抗压位放牌提示；
  - 回合结束时弃牌与回手结算信息。
