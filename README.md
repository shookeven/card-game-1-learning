# card-game-1-learning

一个可运行的 Python 命令行卡牌小游戏（3 人，1v2 非对称，MVP-0）。

## 规则（MVP-0）

- 牌库共 29 张，仅包含名称与数量（不实现技能），使用正式牌库定义（见 `game/cards.py`）。
- 开局：每人 9 张手牌，剩余 2 张为底牌并公开可见；在阵营确定后两张底牌归进攻方，进攻方手牌变为 11 张。
- 阵营：
  - 手牌含“快手杰克”的玩家为进攻方；
  - 若无人拥有“快手杰克”，随机指定进攻方；
  - 其余两名玩家为防守方，按玩家编号小者=抗压位，大者=支援位。
- 回合流程：
  1. 出牌阶段：按 `进攻方 -> 抗压位 -> 支援位` 顺序，各自背面放置 1 张。
  2. 信息可见性：支援位可见抗压位放置的牌，其余背面信息不可见。
  3. 启动阶段（占位）：按批次推进（第2→3→4→5批），系统会提示“进入第X批次”；每个批次先按牌优先级结算，再在同优先级内按玩家顺序（进攻方→抗压位→支援位）。若技能要求“启动阶段重置”，则立即回到第1个批次重新推进。
  4. 回合结束：
     - 翻面牌进入弃牌区（永久移出）；
     - 未翻面牌回到所属玩家手牌；
     - 若本轮无人翻面，则战场所有牌直接进入弃牌区。
- 胜利条件：出牌阶段时若某阵营所有玩家均无牌可出，则该阵营失败。
- 平局条件：若出牌阶段开始时进攻方与两名防守方都无牌可出，则直接判定平局。
- MVP-3 战斗核心：
  - 击败（击杀/毒杀）成功后，击败者必须立即将目标牌加入自己手牌（不进弃牌区）。
  - 击杀/毒杀目标可选任意场上牌（含友方）。
  - 区分 kill 与 poison：铁臂祭司免疫击杀但不免疫毒杀。
  - 本回合被击败的牌记录在 `defeated_this_round`，本回合不能启动主动技能。
  - 本版实现主动技能：铁手巴特（击杀1张）、圣言巴特（击杀1张）、女巫（毒杀1张）；铁臂祭司实现被动免疫击杀。
  - 夜鸦：翻面后展示当前战场，夜鸦进入弃牌区，立刻补放1张背面牌，并重置启动阶段。
  - 哈伯克拉底：翻面后沉默场上一张牌（本回合主动/被动技能视为空白），哈伯克拉底进入弃牌区，立刻补放1张背面牌，并重置启动阶段。
  - 快手杰克（第2批）：选择1名目标牌手，随机抽取其2张手牌（不足则全部）展示给使用者；使用者选1张背面放置到自己战场；快手杰克随后进入弃牌区并立即重置启动阶段。若目标手牌为空导致无目标，则快手杰克回手且不重置。
  - 天引（第2批）：选择战场上一张牌加入自己手牌（不能选择这张天引自身）；天引随后进入弃牌区。若无可选目标，则天引回手。
  - `silenced_this_round` 会在回合结束时清除。
  - 主动技能不能以自身为目标。

## Windows 环境运行

### 1) 创建并激活虚拟环境

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2) 安装依赖

```powershell
python -m pip install -U pip
pip install pytest
```

### 3) 运行游戏

```powershell
python main.py
```

## 输入说明

- 出牌阶段：输入手牌索引（如 `0`、`1`）选择本回合背面放置的牌。
- 启动阶段：输入 `y` / `n`（或 `yes` / `no`）决定是否翻面自己战场牌。
- 程序会显示：
  - 公开底牌；
  - 每位玩家角色；
  - 支援位可见的抗压位放牌提示；
  - 回合结束时弃牌与回手结算信息。

## 运行测试

```bash
pytest -q
```
